# PO:DL Vietnam Wiki

Trang nội bộ của Inside Bridge VN về thương hiệu PO:DL tại Việt Nam.

Nội dung:
- Thương hiệu: Pore-Obsession, Sensory Standard™, thông điệp chính, routine dòng Chestnut
- Sản phẩm: 14 SKU bán tại Việt Nam, chi tiết theo Product Bible
- Thuật ngữ thành phần & công nghệ
- Claims & marketing guardrails
- Kênh chính thức

Nguồn dữ liệu: [VI] PO:DL Overall File (Google Sheets). Mỗi trang (`vn/`, `kr/`) là một file HTML, ảnh đã nhúng sẵn, mở trực tiếp bằng trình duyệt.

## Link

- Tiếng Việt: https://insidebridgevn.github.io/podl-vietnam/vn/
- Tiếng Hàn: https://insidebridgevn.github.io/podl-vietnam/kr/

Link gốc tự chuyển sang /vn/ (sau khi bật GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root)

## File

- `vn/index.html`, `kr/index.html`: trang tiếng Việt và tiếng Hàn (cùng nội dung, mở theo ngôn ngữ)
- `index.html`: tự chuyển sang /vn/
- `favicon.ico`, `favicon-16x16.png`, `favicon-32x32.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`: icon
- `og-image.jpg`: ảnh preview khi chia sẻ link (Zalo, Messenger, Slack…)
- `site.webmanifest`: thêm trang ra màn hình chính điện thoại
